# Feliz cumpleaños
Abre index.html en tu navegador. Coloca las fotos numeradas en img/ (1.jpg, 2.png, etc.) y edita **solo** `totalFotos` en script.js: es la única fuente de configuración y de ella dependen el carrusel de portada, la galería y el visor (lightbox). La portada rota automáticamente cada 4 segundos con indicadores de posición, la galería muestra todas las fotografías y cualquier imagen se amplía en el visor con navegación por teclado, flechas, gestos táctiles, contador y cierre con Escape o clic fuera. Puedes personalizar los textos en index.html y los colores en styles.css. Para GitHub Pages, sube el contenido de esta carpeta a la raíz del repositorio y activa Pages desde Settings > Pages, seleccionando la rama y la carpeta raíz. No requiere instalación ni dependencias externas.
